# Issue Tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues under
`twocngdagz/codemoot`. Use the `gh` CLI for issue operations.

## Conventions

- Create: `gh issue create --repo twocngdagz/codemoot --title "..." --body "..."`
- Read: `gh issue view <number> --repo twocngdagz/codemoot --comments`
- List: `gh issue list --repo twocngdagz/codemoot --state open`
- Comment: `gh issue comment <number> --repo twocngdagz/codemoot --body "..."`
- Add or remove labels with `gh issue edit`.
- Close with `gh issue close`.

Use heredocs or body files for multiline issue bodies. Any issue or comment generated
during AI-assisted triage must begin with:

> *This was generated by AI during triage.*

When a skill says to publish something to the issue tracker, create a GitHub issue.
When it asks for the relevant ticket, fetch the issue and its comments with `gh`.
